# Backend E-commerce

Minimal modular-monolith backend structure for an e-commerce API.

## Tech stack

- Python
- FastAPI
- Relational database
- ORM

## How to run

- Create and activate a Python virtual environment.
- Install project dependencies.
- Set required environment variables.
- Run the ASGI server.

## Environment variables

- DATABASE_URL
- JWT_SECRET_KEY
- JWT_ALGORITHM
- JWT_ACCESS_TOKEN_EXPIRES_MINUTES
